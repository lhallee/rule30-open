# Agents working on rule30-open

This repository works on the three Rule 30 Prize problems in the open. [CONTRIBUTING.md](CONTRIBUTING.md) holds every
rule and every how-to and binds agents exactly as it binds people, so read it before you change anything.
[README.md](README.md) orients, and [ROADMAP.md](ROADMAP.md#next-steps) and [CATALOG.md](CATALOG.md#open-work) list the
open work. Beyond CONTRIBUTING, run `lake build` and `python scripts/catalog.py audit` before you say that a theorem is
proved, whether in an entry, a commit message, or a report.
