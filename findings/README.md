# Findings

Results that are not (yet) proved in Lean: proved on paper (`status: paper`), established by computation
(`computed`), or conjectured from evidence (`conjecture`). Each says how far it is formalized, with `formalization:`
`wanted`, `partial`, `kit` (the kit proves it in Lean) or `not-applicable`. A finding whose code is in this repository
lists it under `evidence`, and one without `evidence` is proved on paper or says that its code is not here. One directory
per category of [categories.yaml](../categories.yaml). [CATALOG.md](../CATALOG.md) lists them all,
[CONTRIBUTING.md](../CONTRIBUTING.md) gives the format, and [GLOSSARY.md](../GLOSSARY.md) defines the terms they use.

A finding marked `formalization: wanted` is an open task: turn it into a Lean module with its argument.
