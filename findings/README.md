# Findings

Results that are not (yet) proved in Lean: proved on paper (`status: paper`), established by computation
(`computed`), or conjectured from evidence (`conjecture`). Each says how far it is formalized (`formalization: wanted`,
`partial` or `not-applicable`) and lists the code that reproduces it under `evidence`. One directory per category of
[categories.yaml](../categories.yaml); [CATALOG.md](../CATALOG.md) lists them all, and
[CONTRIBUTING.md](../CONTRIBUTING.md) gives the format.

A finding marked `formalization: wanted` is an open task: turn it into a Lean module with its argument.
