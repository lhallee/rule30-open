# Negative results

What was tried on the Rule 30 Prize problems and did not work, with the reason, so nobody repeats it blind. Each entry
has a `kind`:

- `no-signal`: a search or test that found nothing, with the controls that show what it could have found.
- `refuted`: a conjecture or picture that is false, with the counterexample.
- `dead-end`: an approach that reduces to something as hard as the problem, with the step where it stops.
- `barrier`: a reason a whole class of approaches cannot work.

A negative result is only as useful as its stopping point is precise. If you find a way past one, link your entry to it
rather than deleting it. [CATALOG.md](../CATALOG.md) lists them all by category.
